# Figma Wireframes: Social Leaderboards

This document outlines the wireframes for the new Social Leaderboards feature in the Fit Maxxing application.

## 1. Leaderboard Tab

*   **Description:** A new "Leaderboards" tab will be added to the main navigation bar.
*   **Placement:** It will be placed between the "Stats" and "History" tabs.
*   **Icon:** A trophy icon will be used for the tab.

## 2. Leaderboard View

*   **Description:** This is the main view for the leaderboards. It will have two sub-tabs: "Global" and "Friends".
*   **Components:**
    *   **Sub-tabs:** "Global" and "Friends" tabs to switch between the two leaderboard types.
    *   **Filter:** A dropdown filter to switch between "Weekly" and "All-Time" rankings.
    *   **Ranking List:** A scrollable list of users, displaying their rank, avatar, username, and XP/Rank.
    *   **User's Position:** The current user's position will be highlighted in the list.

## 3. Friends List Management

*   **Description:** A simple interface to manage the user's friends list.
*   **Access:** This can be accessed through a "Manage Friends" button on the "Friends" leaderboard.
*   **Components:**
    *   **Add Friend:** An input field to search for and add new friends by their username.
    *   **Friends List:** A list of the user's current friends with an option to remove them.
